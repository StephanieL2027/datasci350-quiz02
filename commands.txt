---title: "Budget and Revenue"---```{python}import pandas as pdimport matplotlib.pyplot as pltfilms = pd.read_csv("films.csv")```@fig-budget-revenue shows each film's production budget and its revenue.```{python}#| echo: true#| label: fig-budget-revenue#| fig-cap: "Budget and revenue, in millions US dollars"plt.scatter(films["budget_musd"], films["revenue_musd"])plt.xlabel("Budget (million USD)")plt.ylabel("Revenue (million USD)")plt.show()```

touch runtime-rating.qmd
---title: "Runtime and Ratings"---```{python}import pandas as pdimport matplotlib.pyplot as pltfilms = pd.read_csv("films.csv")```@fig-runtime-rating shows each film's runtime and rating. ```{python}#| echo: true#| label: fig-runtime-rating#| fig-cap: "Runtime and Rating"plt.scatter(films["runtime_min"], films["imdb_rating"])plt.xlabel("Runtime (minutes)")plt.ylabel("IMDb rating")plt.show()``````{python}#| echo: truefilms["decade"] = films["year"] // 10 * 10films.groupby("decade")["imdb_rating"].mean().round(2)```

---title: "The Bond Films"---```{python}import pandas as pdimport matplotlib.pyplot as pltfilms = pd.read_csv("films.csv")bond = films[films["franchise"] == "James Bond"]``````{python}#| echo: false#| output: asisprint(f"The Bond films in this dataset run from {int(bond['year'].min())} to {int(bond['year'].max())}.")``````{python}#| echo: trueplt.plot(bond["year"], bond["revenue_musd"])plt.xlabel("Year")plt.ylabel("Revenue (million USD)")plt.show()```
